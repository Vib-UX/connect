While the agents work

Wait
Two people, two agents, both still running. That overlap is the match.
Battle
Chess if you want a board. Flappy if you want a score. Multiplayer, inside Cursor or Claude. The agents keep working.
Cover
Each side locks a tokenised stock or BNB, sized to the same dollars. Winner gets both piles and the prompt is paid for.

Stakes sit in ShareEscrow on BNB Chain. One player can lock a stock. The other can lock BNB. The game only names the winner.
